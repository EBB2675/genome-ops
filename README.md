## Small project for exploring raw DNA data

### Goals
- Parse raw genotype data
- Filter SNPs by chromosome, position, RSID, or genotype
- Run basic statistics and exploratory analysis
- Experiment with simple genomics algorithms and visualizations
- Annotate selected variants
- Investigate HBB-related variants relevant to beta thalassemia

### Disclaimer

This is a hobby project for visualizing, exploring and experimenting with raw DNA data
